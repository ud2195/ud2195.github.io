LayR — AI-powered digital closet & personal stylist

Founder•2025 → Present•Consumer AI

LayR helps users finally wear everything they own — with confidence. It organizes wardrobes, understands body shape & color palette, and generates personalized outfits in seconds.

  • Style profiling: body shape + color analysis + preference capture → consistent personalization.
  • Wardrobe intelligence: item metadata extraction, tagging, and retrieval to power instant outfit ideas.
  • Outfit generation: occasion-aware recommendations with saving/recall loops for retention.
  • AI-native UX loops: upload → value → save → notification/plan → repeat.

Why it’s hard (and what I solved)

AI styling isn’t just model demos — it’s latency, costs, and product loops. I focus on making the system feel instant, reliable, and habit-forming.

  • Latency discipline: caching + batching + model selection to keep experiences snappy.
  • Quality evaluation: human-in-the-loop and LLM-assisted judging to ship improvements safely.
  • Practical infra: AWS-first design (serverless + managed services) with production monitoring.
  • Growth-friendly outputs: content-ready transformations for short-form sharing loops.

Selected Work

How I think: constraints → system → shipped outcome

Retrieval systems that balance quality + cost

I approach retrieval like a product: quality metrics are necessary, but not sufficient. The winning system optimizes quality while respecting latency, memory, and infra constraints.

  • Trade-offs: embedding dimensionality vs storage vs latency vs quality.
  • Indexing: KNN/HNSW/IVF choices based on constraints, not hype.
  • Evaluation: offline metrics + calibrated human/LLM judgments.

UX loops for AI products

AI is only “magic” if users come back. I design loops that create repeated value: trigger → action → reward → next trigger.

  • Personalization loop: profile → better recs → refinement → better recs.
  • Wardrobe loop: upload items → outfits improve → upload more items.
  • Share loop: transformations → short-form content → installs → more content.
